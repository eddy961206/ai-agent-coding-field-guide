조사 범위와 읽는 법

  • 로그인된 X 검색, 공개 게시물 본문, GitHub 원본 문서, 공식 글과 Reddit 원문·댓글을 확인했어. 공개 X 본문 확인에는 FxTwitter API도 보조적으로 사용했어. X 작성 시각은 KST 날짜로 변환했어.
  • 소셜 검색은 전수조사가 아니야. 검색 순위, 삭제·접근 제한, 주제 선택에 따른 편향이 있어. 인기 수치를 신뢰도 점수로 사용하지 않았어.
  • Reddit 일부는 검색 결과에 표시된 절대 날짜를 사용했어. 정확한 UTC 시각을 확보하지 못해 KST 날짜라고 표시하지 않았어. 작성일이 불명확한 항목은 그대로 남겼어.
  • GitHub 문서는 원본과 확인한 커밋 링크를 보관해. 명령과 기능은 이후 바뀔 수 있어. 도구 설치, 효과 재현, 전체 코드 감사는 별도로 수행하지 않았어.
  • 개인 경험, 회사 자체 보고, 연구, 편집 제안을 구분해 읽어줘. 연결된 영상과 이미지를 전부 분석한 것은 아니며 이 판은 확인한 텍스트를 중심으로 정리했어.
  • 도식과 적용 도우미는 설명용이야. 실제 검사 결과나 성능 순위가 아니야. 원문 전문을 재배포하지 않아.
