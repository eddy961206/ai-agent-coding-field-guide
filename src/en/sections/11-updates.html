Scope of the privacy mod

Our previous edition described the changelog and team member’s account of checks for web or shell calls. The newly reviewed public cc-plugin-privacy documentation says this mod checks only some shell inputs, excluding WebFetch, WebSearch, MCP and values inside scripts.

RECORDED 2026-11-02 · SKILL EVAL

Compare before keeping a skill

In a small report, twelve of sixteen counted skills scored above same-length placebo text on at least one of three text tasks and below it on none. The same Haiku model generated and graded answers.

Beating placebo does not establish an advantage over no skill. Test poteto’s prediction of shorter skills on actual work too.
