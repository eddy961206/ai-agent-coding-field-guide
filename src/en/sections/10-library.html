Research scope and how to read it

  • We reviewed logged-in X searches, public post text, original GitHub documents, official articles, and Reddit posts and comments. We also used the FxTwitter API to help check public X text. X publication timestamps were converted to KST dates.
  • Social search is not exhaustive. Search rankings, deleted or restricted content, and topic selection introduce bias. We did not use popularity metrics as reliability scores.
  • For some Reddit entries, we used absolute dates shown in search results. We did not obtain exact UTC timestamps, so we have not labeled these as KST dates. Unknown publication dates remain unknown.
  • For GitHub documents, we keep the original URL and the inspected commit link. Commands and features may change later. We did not separately install the tools, reproduce their claimed effects or audit their entire codebases.
  • Distinguish personal experience, company reports, research and editorial suggestions. We did not analyze every linked video or image. This edition primarily summarizes text we checked.
  • Diagrams and the task chooser are explanatory aids, not actual verification results or performance rankings. We do not republish full source texts.
