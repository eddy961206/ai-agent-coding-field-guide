How to apply this to your work

Before adding “don’t make this mistake,” look for examples, APIs, or data structures that encouraged it. Choose the smallest change that prevents recurrence, then check that it really rules out the forbidden state.

For example, explicitly define allowed states and transitions instead of using several booleans that can contradict each other. This is an illustrative example, not a diagnosis of any particular code.
