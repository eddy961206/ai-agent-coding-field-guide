## 도구가 실제로 지침을 읽는 조건

- [Claude Code 지침 공식 문서](https://code.claude.com/docs/en/memory)는 직접적인 `AGENTS.md` 지원에 v2.1.277 이상이 필요하다고 설명한다. 기본값에서는 현재 작업 경로나 상위의 프로젝트용 `CLAUDE.md` 또는 `CLAUDE.local.md` 등이 있으면 `AGENTS.md` 대신 해당 `CLAUDE.md` 계열을 읽는다. 사용자 홈의 `~/.claude/CLAUDE.md`와 조직 관리 지침은 이 선택을 막는 파일로 세지 않는다. 프로젝트 지침 설정에 따라 둘을 함께 읽도록 바꿀 수도 있다.
- 같은 문서는 `--add-dir`로 더한 폴더의 `CLAUDE.md`를 기본으로 로드하지 않는다고 명시한다. 별도 환경 변수를 켜면 `CLAUDE.md` 계열과 규칙을 읽지만, 해당 추가 디렉터리의 `AGENTS.md`는 그 경로로 읽지 않는다고 구분한다. Windows에서 심볼릭 링크 대신 `@AGENTS.md` 가져오기를 권하는 조건도 안내한다.
- [Claude Code 스킬 공식 문서](https://code.claude.com/docs/en/skills)는 `--add-dir`로 추가한 폴더의 `.claude/skills/`는 로드한다고 설명한다. 일반 세션에서는 스킬 설명을 먼저 맥락에 두고 본문은 호출할 때 읽는다. 미리 지정된 서브에이전트 스킬은 예외다. 스킬 검색을 추가하면 반드시 비용이 줄어든다는 실험 결과는 없다.
- [Codex 지침 공식 문서](https://developers.openai.com/codex/guides/agents-md)는 시작 시 전역 지침과 프로젝트 루트에서 현재 작업 폴더까지의 지침을 결합한다고 설명한다. 홈 저장소에 다른 프로젝트의 경로가 적혀 있다는 사실만으로 해당 프로젝트의 지침이 자동 적용됐다고 가정하지 않는다. 세 공식 문서의 최초 게시일은 미확인이며 11월 12일 내용을 확인했다. 특정 사용자 세션에서 로드 결과는 시험하지 않았다.

## 적용 제안과 다음 확인

여러 사람이 여러 PC에서 작업한다면 공통 지침의 정본과 프로젝트별 고유 규칙을 분리하고, 각 세션에서 실제 적용된 출처와 버전을 기록하는 접근을 먼저 비교한다. 진행 중 요청이나 정책이 바뀌면 이전 버전을 계속 쓸지 자동으로 결정하지 말고, 변경을 알리고 중단·재확인·재개 여부를 정해야 한다. 공통 지침 공유와 이슈 조정, 브랜치 충돌, 접근 제어는 별개다. 이는 편집 제안이며 제품의 검증된 성능 주장이 아니다.

다음에는 실제 허용된 격리 환경에서 두 PC의 동시 수정·충돌과 원복, 각 클라이언트에서 어떤 지침이 실제 적용되는지, 서버 장애와 작업 중 정책 변경을 확인한다. 현재 조사는 실행이나 사용자 설정 변경을 하지 않았다. 원문 메타데이터는 `data/sources.json`, 조사 묶음은 `research/batches/2026-11-12-shared-agent-guidance.json`에 있다.
