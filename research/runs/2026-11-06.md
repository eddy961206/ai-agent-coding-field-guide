# 2026-11-06 조사 기록

## 목적

AI 에이전트를 활용한 효율적인 개발 방법론을 X, Reddit, GitHub와 원작성자의 웹 문서에서 조사했습니다. poteto의 최근 생각을 중심으로 다른 관점, 기존 자료집, 실행 가능한 방법을 비교했습니다. 조사 기준 시간대는 Asia/Seoul입니다.

## 범위와 경로

- X: 로그인된 인앱 브라우저의 작성자·주제 검색. poteto, bcherny, addyosmani, simonw, mitchellh, steipete, trq212, karpathy, GergelyOrosz. 공개 본문은 FxTwitter API로도 대조했습니다. API를 X 전체 검색이나 답글 전수조사로 취급하지 않았습니다.
- GitHub: 자료집과 방법론의 원본 README·문서, 파일별 마지막 변경 커밋. 오래된 검색 결과가 GSD 이전 저장소를 가리키는 경우 새 저장소 안내를 따랐습니다.
- Reddit: 원문 게시물과 특정 댓글을 확인했습니다. 자동 생성된 커뮤니티 요약은 주요 근거로 채택하지 않았습니다. 일부 날짜는 검색 결과에 표시된 원문 댓글의 절대 날짜를 사용했습니다.
- 웹: Simon Willison, HumanLayer, Anthropic, METR, X Engineering, Addy Osmani, PoliMi 서지 등 원작성자 자료.
- 주요 검색 축: agentic engineering patterns / coding workflows / verification / formal methods / context engineering / agent handoff / subagent overhead / curated guides / research freshness.

## 조사에서 특히 달라진 판단

1. 적대적 리뷰에 대한 poteto의 11월 입장은 Addy의 10월 다층 검증 관점과 차이가 있습니다. 보편적 우열로 합치지 않았습니다.
2. 형식 기법은 명세·가정·범위·코드 대응을 함께 설명해야 합니다. 검증 스킬 두 종류를 구분했습니다.
3. 생산성 수치는 PR 개수, 코드량, 작업 시간, 체감 업무 가치를 나눠 읽어야 합니다. METR 5월 설문도 추가했습니다.
4. 자료집은 원문 URL과 작성일뿐 아니라 확인일·수정 이력을 보관해야 다른 에이전트에게 전달하기 좋습니다.

## 관측 한계

전체 게시물이나 검색 결과의 전수조사가 아닙니다. X·Reddit 검색 순위와 접근 제한이 있습니다. Reddit 직접 JSON 조회는 403으로 막혔고 일부 정확한 게시 시각은 확보하지 못했습니다. 날짜를 임의 생성하지 않았습니다.

연결된 영상 전체를 시청하거나 음성을 전사하지 않았습니다. GitHub의 설치 지침을 실행하거나 도구별 효과를 비교 시험하지 않았습니다. 연구 결과의 실험을 재현하지 않았습니다. 개인 경험과 자기보고를 인과적 생산성 효과로 취급하지 않았습니다.
