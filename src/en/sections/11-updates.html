2026-11-13 KST · REDDIT

One agent or a team?

For a booking-app task, one author reports seven runs per setup with the same model: one agent versus a subagent team. Forty held-out tests and median AI design scores matched. Team medians were 28.6 minutes and $1.31 at API list prices; single-agent medians were 15 minutes and $0.81.

The runs used a subscription, with costs estimated at API list prices. Both setups missed a UI flaw, and a commenter reports subagent review helping on a large codebase. One web app does not establish equal quality or a universal winner.

CHECKED 2026-11-12 · OFFICIAL DOCS

Pointing to a folder does not prove loading

Codex docs describe loading global instructions and project instructions from the repository root down to the working directory at session start. By default, Claude Code reads project CLAUDE.md files instead of AGENTS.md when a project CLAUDE.md or CLAUDE.local.md exists in the working path. Versions and settings matter.

Claude Code’s --add-dir loads skills in the added directory but does not load its CLAUDE.md by default. Ordinary sessions load skill descriptions first and full content when invoked; preloaded subagent skills are different.
