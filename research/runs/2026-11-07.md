# 2026-11-07 조사 기록

## 범위

첫 조사판인 2026-11-06을 기준으로 72시간이 겹치도록 2026-11-03부터 조사했다. 기준 시간대는 Asia/Seoul이다. X의 로그인된 검색에서 poteto와 다른 관찰 대상 작성자의 글을 확인했고, Reddit의 r/ClaudeCode 원문과 토론, GitHub 이슈와 공식 변경 이력을 확인했다. 접근 가능한 자료의 선별 조사이며 전수조사는 아니다.

## 이번에 추가한 내용

1. [poteto의 11월 7일 글](https://x.com/poteto/status/2118746525811753061)은 미래 모델이 일부 지침을 흡수해 스킬이 짧아질 수 있다는 예측이다. 오래된 지침을 자동으로 삭제해도 된다는 실험 결과로 취급하지 않는다.
2. [Reddit의 11월 6일 인계 논의](https://www.reddit.com/r/ClaudeCode/comments/1xpaoth/people_keep_building_their_own_tools_to_move_work/)는 대화 전문·요약·형식 변환의 비용과 손실을 비교하는 질문이다. 기각한 접근과 이유도 인계에 남기는 기존 제안을 보강했다. 서로 다른 방식의 우열을 검증한 실험은 아니다.
3. [GitHub의 11월 6일 사용자 보고](https://github.com/anthropics/claude-code/issues/107757)는 macOS의 Claude Code 2.1.318에서 계정 이메일이 요청 헤더에 들어간 사례를 설명한다. [팀원의 11월 7일 설명](https://x.com/addyosmani/status/2118771062913802383)에 따르면 2.1.317 이후 일부 요청에는 확인 절차가 있지만 생성된 스크립트 등 모든 경우를 포착하지 못한다. 이메일을 모델 맥락에서 제거하는 다음 릴리스는 당시 예정이었다. [고정된 공식 변경 이력](https://github.com/anthropics/claude-code/blob/0ed94698aa0aeee471465fc9c867c2e8434c4d68/CHANGELOG.md)은 2.1.317의 확인 항목을 기록한다. 출시 예정과 이미 배포된 수정은 다르다.

## 이전 근거 재확인과 한계

- 기존 pstack README의 마지막 변경은 저장된 `ab1f702`와 같았고, OpenSpec README는 `33c6f93`과 같았다. 수정 시각만 바꾸거나 새 출처로 중복 추가하지 않았다.
- Reddit 게시물의 날짜는 원문 타임스탬프를 KST로 바꿨다. 개별 댓글의 정확한 날짜를 검증하지 않아 댓글을 별도 근거로 채택하지 않았다.
- X와 Reddit 검색 및 답글은 전체를 망라하지 않는다. 검색 색인 지연과 접근 제한으로 누락이 가능하다.
- 계정이나 개인 로그를 확인하지 않았고 Claude Code의 전송 동작을 재현하지 않았다. 사용자 보고만으로 스팸의 원인이나 영향 범위를 확정하지 않았다.
- 스킬 길이, 인계 방식, 성능과 비용을 직접 비교 시험하지 않았다. 원문 작성자의 전망과 편집 적용 제안을 구분한다.
